# Theorem contract — Session 8

## 0. Objects

**Hypergraph.** `H_n`: vertex set `V = [n]^2` (`N = n^2`), edge set = all 3-element
subsets that are the vertex set of a **nondegenerate** isosceles triangle (squared
Euclidean distance; collinear triples are *not* edges). `C(n) = alpha(H_n)`.

**Process** (Bennett–Bohman, arXiv:1308.3732, §1). `I(0) = {}`, `V(0) = V`,
`H(0) = H_n`. At step `i` a vertex `y_i` is chosen **uniformly at random from `V(i)`**
and added to `I`. Then `V(i+1) = V(i) \ {y_i} \ {u : some e in H with e\{u} ⊆ I(i+1)}`.
`H(i)` is `H_n` restricted to `V(i)` with chosen vertices deleted from edges; an edge
containing another edge is discarded.

**Filtration.** `F_i` = sigma-algebra generated by `y_0,...,y_{i-1}`. Every expectation
below is conditional on `F_i`.

**Tracked variables** (BB notation, `r = 3`).
- `d_l(v,i)` = # edges of size `l` in `H(i)` containing `v`, for `l in {2,3}`;
- `d_l^+`, `d_l^-` = created / destroyed counts, `d_l = d_l^+ - d_l^-`;
- `codeg(v,y) = d_{{v,y} up 3}(i)` = # size-3 edges containing both `v` and `y`;
- `c_{2,2->1}(v,v',i)` = # pairs of size-2 edges `f ∋ v`, `f' ∋ v'`, `|f ∩ f'| = 1`.

**Time.** `t = D^{1/2} i / N`, `q(t) = e^{-t^2}`, `s_2(t) = 2 D^{1/2} t q(t)`,
`s_3(t) = D q(t)^2`, `s_2^+(t) = 2 D^{1/2} ∫_0^t q`. Horizon `i_max = t_max N / D^{1/2}`.

**Tolerance.** A *tolerance schedule* is a positive function `tol(t)`. It is **admissible**
if `tol(t) <= sigma(n) * s_2(t)` for some `sigma(n) = o(1)` — the minimum requirement for
the differential-equation method to determine the trajectory to leading order.

## 1. What is being asked

BB's stopping time `T` (ind.tex line 720) halts at the first `i` where **any** of four
conditions fails, two of which are quantified over **all** vertices or **all** pairs:

| # | condition | quantifier | for `r = 3` |
|---|---|---|---|
| (P) | `\|V(i)\| ∈ Nq ± ND^{-δ} f_v` | scalar | — |
| (V) | `d_l^± (v) ∈ s_l^± ± D^{(l-1)/2-δ} f_l` | all `v ∈ V(i)` | `l = 2, 3` |
| (S) | `d_{A up b} <= D_{a up b}` | all pairs `A` | monotone ⇒ deterministic |
| (C) | `c_{a,a'->k}(v,v') <= C_{a,a'->k}` | all pairs `v,v'` | only `(2,2->1)` is dynamic |

The session target is to replace a pointwise worst-case pair condition by a dynamically
weighted exceptional budget. The contract below fixes **which** condition, **which**
statistic, and **which** proof term.

## 2. The exceptional-pair statistic and its weight

For `v ∈ V(i)` and threshold `tau > 0`:

```
B_v(i, tau) := # { y ∈ V(i) : codeg(v,y) > tau }         (static count at time i)

Lambda_v(tau) := sum_{i < T}  B_v(i,tau) / |V(i)|         (predictable cumulative hazard)

Lambda_v^w(tau) := sum_{i < T}  (1/|V(i)|) * sum_{y ∈ V(i), codeg(v,y) > tau} codeg(v,y)
                                                          (dynamically weighted hazard)
```

`Lambda_v` is **predictable** (`F_i`-measurable at each step) and, because `codeg` is
monotone non-increasing along the process, is bounded by a deterministic function of the
*initial* hypergraph and of `min_i |V(i)|`.

The **proof term these control** is the one-step increment

```
Delta d_2^+(v, i)  =  ( # size-2 edges at v created when y_i is chosen )  <=  codeg(v, y_i),
```

which enters at exactly two places in the primary source:

- **ind.tex line 1172** — as the maximum step `eta` in the asymmetric Azuma bound for
  `Z_2^+(v) := d_2^+(v) - s_2^+ - D^{1/2-δ} f_2`;
- **ind.tex line 1018** — inside the drift of `Z_l^-(v)` only through the *sum*
  `Sigma_l(v) = sum_{e ∈ d_l(v)} sum_{u ∈ e\{v}} d_2(u)`, i.e. never pointwise.

## 3. Candidate theorem (statement to be proved or refuted)

> **Candidate A (averaged stopping time).** There are constants `c, C` such that if the
> pointwise condition (V) for `l = 2` in BB's stopping time is replaced by
>
> - **(A0)** `max_{v ∈ V(i)} d_2(v) <= s_2(t) * log^{1/2} N` (a crude cap, all `v`), and
> - **(A1)** `| sum_{v ∈ V(i)} d_2(v) - |V(i)| s_2(t) | <= |V(i)| * tol(t)` (one scalar), and
> - **(A2)** for all `v ∈ V(i)` and `l ∈ {2,3}`:
>   `| Sigma_l(v) / ((l-1) d_l(v)) - s_2(t) | <= tol(t)` (neighbourhood average),
>
> the remaining conditions being unchanged, then the conclusion
> `|I| = Omega(N (log N / D)^{1/2})` still holds with probability `1 - o(1)`.

> **Candidate B (grid instance).** `H_n` satisfies (A0), (A1), (A2) with an admissible
> tolerance through the horizon `t_max = Theta(1)`, whence `C(n) = Omega(n)`.

**Control type.** (A0) with high probability; (A1) with high probability, scalar, no union
bound; (A2) with high probability *per vertex*, union bound over `N` vertices, valid only
for `i < T`. All statements conditional on the stopped filtration `F_{i ∧ T}`.

## 4. Counterexample-first obligation

Before proving Candidate A, the following must be checked, because if it fails the
candidate is either false or vacuous:

- **(X1)** Is the *original* pointwise condition (V) for `l = 2` actually true for `H_n`?
  If it is, Candidate A is unnecessary. If it is **false**, that is itself a theorem and it
  forces the shape of any correct analysis.
- **(X2)** Can (V) for `l = 2` be established for `H_n` by *any* concentration inequality
  plus a union bound over vertices? (This is a statement about achievable exponents, not
  about a particular inequality.)
- **(X3)** Does replacing pointwise by averaged control actually remove the obstruction, or
  does the same heavy tail reappear in the averaged statistic?

These are resolved in `THEOREM_AND_PROOF.md` (Thm 2, Thm 3) and `ATTACK_LOG.md`.

## 5. Logical bridge to `C(n)`

```
Candidate A  +  Candidate B
   ⇒ random greedy on H_n survives Theta(n) steps whp
   ⇒ |I| = Omega( N (log N / D)^{1/2} ) = Omega( n^2 * (log n / (n^2 log n))^{1/2} ) = Omega(n)
   ⇒ C(n) = Omega(n),  a strict improvement on the known Omega(n / sqrt(log n)).
```

The arithmetic input to the bridge is `D(H_n) = Theta(n^2 log n)` (Lemma 1(d)), which is
what makes `(log N / D)^{1/2} = Theta(1/n)` rather than `Theta(1/(n sqrt(log n)))`.

**A conditional Candidate A with unverified Candidate B is not a grid result** and must be
recorded as a conditional bridge only.
