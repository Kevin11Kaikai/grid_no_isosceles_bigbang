Working note · isosceles-free sets in the grid

The √log n gap is in the analysis, not in the truth

The known lower bound for isosceles-free subsets of the grid is exactly the alteration threshold. The greedy process that produces such sets beats that threshold by the missing factor. This note locates the gap precisely, in three hypotheses of one theorem.

1. The problem

For a positive integer n let C(n) be the largest size of a set S ⊆ [n]² containing no three distinct points a,b,c with d(a,b) = d(b,c) — no isosceles triple, degenerate collinear ones included. Equivalently: from every point of S, all squared distances to the other points of S are distinct.

Exact values are known with proved optimality for n ≲ 32 by SAT search; the first open case is n = 33. The asymptotic state is

n / √(log n) ≲ C(n) ≲ exp(−c (log n)^(1/9)) · n²

and the live question is the lower end. Jánosik, Nagy, Szabó and others (arXiv:2601.14465) observe that the known bound is sublinear, conjecture that the truth is linear, and name the route: “most probably a linear lower bound can be achieved via the random independent set process.” Nobody has carried it out.

2. One formula produces the known bound

Work in the 3-uniform isosceles hypergraph H on the ambient point set: each edge is an isosceles triple, and each edge has a unique apex (two apexes would force an equilateral lattice triangle, which does not exist). For an apex a write N_a(d) for the number of points at squared distance d from a, and let

P = E_a[ Σ_d N_a(d)² ] / (V−1)² = μ / V
V = size of the ambient set, μ = Σ N² / Σ N = size-biased mean multiplicity of a squared distance

be the probability that two random points are equidistant from a random apex. A random m-set spans about m³P isosceles triples; deleting one point per triple leaves something only while m³P < m. So alteration, and random greedy with it, survive to

m < P^(−1/2) = √( V / μ )

In the grid, V = n² and μ ≍ log n, because Σ_{d≤X} r₂(d)² ≍ X log X for the sum-of-two-squares representation function. That gives n/√(log n) — the known bound is this threshold. Measured directly: P·n²/ln n converges (1.580, 1.513, 1.479, 1.445, 1.426, 1.405, 1.394 for n = 8…64), and P^(−1/2) tracks n/√(ln n) at ratio 0.80 → 0.85.

3. Five ways to attack it, all blocked by the same quantity

The obvious escape is to change V or μ. Each attempt fails, and the failures are informative rather than accidental.

3.1 Strengthen to all distances distinct

Making every pairwise distance distinct — a planar Sidon set — would trivialise the apex condition. It is provably too weak: C(m,2) ≤ Ndist(n) ~ K·2n²/√(log n) by Landau–Ramanujan, so m = O(n/(log n)^(1/4)). Computed exactly, the ratio cap/n is 0.938, 0.906, 0.875, 0.844, 0.816, 0.793, 0.773 for n = 16…1024 — monotonically decreasing. Any proof of linearity must genuinely exploit that only same-apex distances need be distinct.

3.2 First moment and the Local Lemma

Vacuous by a factor of n: at the last step of a one-point-per-column construction there are about n²/8 forbidden events against n available values. Even after filtering to the events that actually forbid something, the effective count scales like n^1.37.

3.3 Pass to a bounded-degree ground set

Restricting to a set where each apex sees each distance at most k times removes the log from the degree. But the largest such set has size Θ(n^(2−2/(k+1)) / (log n)^(α_k)) with α_k = (2^k − 1)/(k+1), doubly exponential in k. Granting the nibble outright, the best attainable is below n for every k, and asymptotically worse than n/√(log n). At n = 10⁶ the route peaks at k = 2 with about 7.1×10³, against a known bound of 2.69×10⁵ — a factor 38 below what is already proved.

3.4 Self-similar doubling

There is an exact free separation in Z²: differences (even,even) give |p−q|² ≡ 0 (mod 4) and (odd,odd) give ≡ 2 (mod 8), so in T = 2S ∪ (2S+(1,1)) the two parity classes can never collide. This yields a genuine recurrence C(2n) ≥ 2·C_H(n), where C_H imposes one extra condition (H). It fails because (H) is itself an r₂-condition: by (2w+1)² + (2z+1)² = 8(T(w)+T(z)) + 2 the cross-class distances are sums of two odd squares, with the same representation statistics. Each point then carries three injectivity families instead of one, so C_H/C → 1/√3 ≈ 0.577 — measured 0.58–0.62 for n = 14…48, and exactly 0.50–0.80 for n = 3…7. Density multiplies by that constant per doubling and decays to zero. Dilation by q preserves the class count only for q a power of two.

3.5 Flatten the arithmetic mod p

The sharpest attempt: work where the obstruction does not exist. If S ⊆ [0,p)² has all same-apex squared distances distinct mod p, they are distinct as integers, so S is isosceles-free in Z² — no wraparound argument needed. And for p ≡ 3 (mod 4) the form u_x²+u_y² is the norm form of F_{p²}, where every nonzero value has exactly p+1 preimages. The multiplicity is perfectly flat.

It collapses to √p. Measured, A(p)/p falls 0.636 → 0.135 over p = 11…401 while A(p)/√p is flat at 2.11 → 2.70. The reason is exactly the threshold formula: flattening μ also collapses the range of distance values from ~p²/√(log p) to p−1, so μ goes from log n to p — the wrong way.

Since μ ≥ V / (#distinct distance values), the threshold is at most √(#distinct values). Uniformity of the multiplicity function and largeness of its range are coupled. No quotient of Z² buys the first without paying more for the second.

4. But the process itself is linear

All of the above bounds what standard analyses deliver. The process they analyse does better. Random greedy on [n]² — vertices in uniformly random order, accept a point iff the set stays isosceles-free — was measured to n = 8192:

The residual decay is real but is the finite-size signature of a lnln n / ln n correction, not a power of log n. The heuristic ∫₀^M e^{am²}dm = N with a = D/N² gives K γ² ln n = ln n + lnln n + O(1), i.e. γ² = A + B·(lnln n/ln n) + C/ln n with γ → √A > 0. And its extrapolated constant is confirmed independently: the heuristic predicts γ_∞ = 1/√K where K = lim D/(n² ln n), and an exact edge count — using no greedy data at all — gives K = 1.81, hence 0.743, against the fitted 0.716.

The random independent set process achieves Θ(n). The √log n deficit is not a gap between the truth and the conjecture. It is a gap between the truth and the analysis.

5. Where the analysis stops, exactly

Bennett–Bohman (arXiv:1308.3732, Thm 1.1) is the natural tool: for an r-uniform, D-regular H on N vertices with D > N^ε, if Δ_ℓ(H) < D^((r−ℓ)/(r−1) − ε) for ℓ = 2..r−1 and Γ(H) < D^(1−ε), then random greedy gives |I| = Ω(N (log N / D)^(1/(r−1))). For the isosceles hypergraph that conclusion is exactly Ω(n) — and numerically it predicts the measured greedy size to within 1–3%.

The hypotheses fail. Here is the whole of the damage, with Γ as they define it: the maximum over distinct v,v' of the number of edge pairs e,e' with v ∈ e∖e', v' ∈ e'∖e, |e ∩ e'| = r−1.

Not one of them fails polynomially. Each fails by a logarithmic factor — the same logarithm that §2 traced to Σ r₂(d)² ≍ X log X. For Γ this is measured: Γ·ln n / D = 0.3327, 0.3100, 0.2984 for n = 32,64,128, converging to the predicted 0.287.

That is what one gets by comparing the hypotheses as they are stated. §7 argues it is the wrong comparison.

6. And the Γ failure is rare

Γ is a maximum. Its distribution is far more forgiving. Writing Γ(v,v') = |P(v) ∩ P(v')| with P(v) the set of pairs forming an isosceles triple with v:

Against the threshold, median Γ / D^0.9 = 2.4e−2, 2.8e−3, 9.4e−4, 9.9e−5 for n = 32,128,256,1024: satisfied by four to five orders of magnitude, with the margin widening.

The bad pairs are those whose difference has a short primitive direction, so that the perpendicular bisector is rich in lattice points. The four extremal families are exactly the directions whose bisector-reflection preserves Z² — reflection with primitive normal (p,q) is integral only when p²+q² ∈ {1,2}: row, column, diagonal, anti-diagonal — which is where the 4/n comes from. A random difference vector has primitive direction of norm ~n², so the bad set is Θ(1/n) = Θ(N^(−1/2)) of all pairs.

7. What the proof actually consumes

The two failing hypotheses are stated as maxima over pairs. Reading the proof shows they are not used that way.

Γ appears exactly once. Bennett–Bohman track auxiliary variables c_{a,a'→k}(v,v') counting pairs of partially-shrunk edges through v and v'; at time zero c_{r,r→r−1}(v,v') is the (r−1)-codegree of that pair, and the hypothesis serves as the base case of the induction bounding it — “the base case following immediately from the condition on Γ(H)”. The induction is diagonal: each pair's chain is driven only by that same pair's variables. And the one place the chain's output is spent is the drift of d_ℓ^−(v), where the error term is not a maximum but a sum — “the number of y that are counted more than once … is at most binom(ℓ−1,2)·C_{2,2→1}” — running over the pairs that lie in a common edge with v, against a main term of order d_ℓ(v)·D^(1/(r−1)).

So the quantity that has to be small is Γ averaged over pairs weighted by how many edges contain the pair, and the same for Δ₂. That weighting is adversarial here, and predictably so: the bad pairs of §6 are mirror pairs, whose perpendicular bisectors are rich in lattice points, so they sit in many edges. The bias is real and grows like 0.27√n. It is not enough.

Fitted as powers of D across its 107-fold range, Γ_edge ≍ D^0.60 and Δ₂_edge ≍ D^0.24: both hypotheses hold on average at ε ≈ 0.26 — polynomial room, not logarithmic. For the maxima the exponent is zero up to logarithms, since Γ_max = Θ(n²) against D = Θ(n² log n). The failure in §5 is an artefact of taking a maximum.

Can the pointwise conditions Δ₂ ≤ D_{a↑b} and c_{a,a'→k}(v,v') ≤ C_{a,a'→k} in the definition of the stopping time be replaced by vertex-aggregated ones — and the drift and Freedman estimates re-derived under the weaker condition?

That is the price, and it is not small. These quantities do not enter as inequalities that merely have to be true; they enter through the stopping time, which halts the moment one pair breaches its bound, however small the aggregate error. Aggregating them demands dynamic concentration for a sum of ~D correlated variables — and Bennett–Bohman say of exactly these variables that they “do not establish dynamic concentration … but we only need relatively crude upper bounds.” The route asks more of the proof in exchange for asking less of the hypergraph. In its favour, the union bound shrinks from N² pairs to N vertices, and the numbers have ε ≈ 0.26 of room rather than none. Whether the trade closes is open — and it does not split into an easier half. The one role Δ₂ has that Γ does not is the step size in the Azuma bound for d_ℓ⁺(v), where the step is the codegree at a uniformly random partner rather than a maximum, which makes truncation look available. It is not: measured at n = 32…160, the only truncation level satisfying the criterion is Δ₂max itself — the original hypothesis — because each vertex has Θ(1) partners sitting exactly at its maximum codegree, and the process runs Θ(n) steps in which all N vertices must survive. Truncating one below the maximum already costs Θ(n) against a requirement of ≪ 1. Without truncation the Freedman exponent is short of log N by a flat factor of about 8 across a six-fold range of n, closing only like √(log D). So both halves need the same thing: an argument tolerating a Θ(1/n) fraction of bad (vertex, partner) events across Θ(n) steps, which is exactly what a pointwise stopping time forbids.

7.1 The third hypothesis, on the other hand, is free

Irregularity turns out to cost nothing. The degree of a point of [n]² is exact and computable — every edge has a unique apex, since two apexes would force an equilateral triangle and Z² has none — and the profile is a smooth bowl: minimum at the corner, maximum at the centre, D_max/D_avg = 1.470 with no trend from n = 16 to 160.

Regularising downward is not available, since deleting edges of the isosceles hypergraph would admit sets that are not isosceles-free. Regularising upward is, and it is free. Let D* = max_v deg(v) and add a 3-uniform R with deg_R(v) = D* − deg(v), drawn independently of the lattice. Then H ∪ R is D*-regular, and an independent set in it contains no edge of the original, so it is still isosceles-free — the bound transfers verbatim. The cost is the constant √1.470 = 1.21: with D* = 2.55 n² ln n, the Bennett–Bohman conclusion is 0.885 n, still Ω(n).

What could go wrong is that R breaks the other two hypotheses. It does not. Measured at n = 24…64, Δ₂(R) has mean 6|R|/N(N−1) ≈ 5–7 and max ≈ 40, growing like log N against Δ₂(H) ≍ n; and Γ_R has mean 1.8 ln²n — flat against ln²n across the range — versus Γ(H) ≍ n²/2. So Δ₂ and Γ are unchanged to leading order, and the §7 edge-weighted averages can only fall, since R adds 47% more edges each carrying Γ = O(log²N). At n = 64, though, Δ₂(R) = 40 against Δ₂(H) ≈ 84: the separation is a statement about growth rates, not about small n.

So the list of hypotheses standing between this hypergraph and a linear lower bound is two, not three — and adding R does nothing for either of them, since both are maxima over pairs of a subgraph of H ∪ R. The easy one is gone; the hard two are where §7 left them.

There is also direct evidence that the Γ hypothesis constrains the analysis rather than the process. On synthetic 3-uniform hypergraphs one can hold degree, edge count and Δ₂ fixed and vary only Γ: pair the vertices by a random perfect matching and give each matched pair H shared hub pairs, against a control in which the same hub pairs are handed to two independent random vertices. Concentrating Γ from O(1) up to 0.33·D changes the greedy output by at most 2.4%, and upward:

Trading Γ against the fraction of bad pairs at a fixed degree budget is likewise flat. Two caveats bound what that means. Bennett–Bohman need Γ small for concentration of the quantities they track, and this measures only the final |I|, which is a mean; a hypergraph can have a robust mean and unruly fluctuations. And the actual regime is untestable — D/log D exceeds D^(1−ε) only once D^ε > log D, which for ε = 0.1 needs D ≈ 10²⁰ — so Γ = Θ(D) is a proxy, albeit a harder test than the real one.

One structural remark falls out of building that control. For fixed v, Σ_{v'} Γ(v,v') ≤ D·(Δ₂−1), so at most D·Δ₂/T partners can have Γ ≥ T. For the isosceles hypergraph that is Θ(log n / n) — the rarity in §6 is forced by Δ₂ being small, not a coincidence of the lattice. Any hypergraph with small codegree automatically has few Γ-bad pairs, which is some reason to think the relaxation is the natural one rather than a special plea.

The last two rows deserve emphasis rather than burial. Nothing here is a new bound on C(n). The claim that greedy/n tends to a positive constant rests on eight data points, a model comparison, and a heuristic whose central assumption — that the selected set behaves like a random set of the same density — is exactly the correlation a rigorous proof would have to control. Its 4% agreement with an independently computed constant is encouraging, not conclusive. The Γ values are evaluated at candidate extremal pairs rather than maximised over all ~n⁴, which is the right direction for showing a hypothesis fails and the wrong one for proving Γ = O(n²). The §7 averages are exact over all partners of each sampled apex, but the apexes are sampled — 20 of them below n = 128, 8 above — and the two exponents are fitted over a single decade of D. The uniform-pair mean underlying them agrees to 0.5% with an independently written program at n = 64.

What the note does claim is narrower and, I think, worth stating. The deficit in this problem has a single source; it is one logarithm wide; it appears in five unrelated-looking methods for the same reason; and the process everyone expects to work does work. The obstruction is technical, it lives in a known theorem, and §7 locates it more precisely than “one logarithm”: the two conditions the isosceles hypergraph fails are stated pointwise and consumed on average, and on average it satisfies them with polynomial room. What stands between that observation and a linear lower bound is a stopping time that halts on a single bad pair. The third hypothesis, irregularity, turned out to cost a factor of 1.21 and nothing else. The remaining obligation does not divide: both halves reduce to tolerating a Θ(1/n) fraction of bad pairs across Θ(n) steps, which is a different proof of that theorem rather than a repair to it.
